# Figure contract

Use this reference before drawing a manuscript figure.

## Required contract

```text
Core conclusion:
Results-level question:
Archetype:
Panel map:
Evidence hierarchy:
Statistics/uncertainty:
Source data:
Reviewer risk:
```

## Figure-level logic

Treat one figure = one major claim as a strong default. A panel belongs in the main figure only if it establishes, compares, validates, explains, stresses, generalizes, or bounds that claim.

Useful panel roles include:

- setup or experimental schematic
- representative example
- primary quantitative evidence
- baseline/control
- decomposition or stratification
- orthogonal validation
- perturbation/stress test
- mechanism
- boundary/failure case

Prefer role diversity over metric diversity. Four panels that repeat the same comparison with cosmetic metric changes are weaker than a shorter evidence chain.

## Evidence-chain patterns

Choose only the steps the claim needs:

- validation: establish -> control -> stress-test -> bound
- mechanism: setup -> primary effect -> localization/decomposition -> mechanism -> boundary
- method: define -> benchmark -> robustness -> generality -> limitation
- imaging: representative image -> quantification -> orthogonal validation -> boundary

## Visual hierarchy

Give decisive evidence the largest or clearest visual area. Supporting controls may be smaller, but must remain readable at the final 17 cm width. Do not force equal panel sizes when evidence importance differs.
